# ChatGPT Translate

Free AI-powered translation using ChatGPT with natural, context-aware results - **no API key required**.

## Features

- **Free Translation**: Uses ChatGPT's free translation service, no API key needed
- **50+ Languages**: Support for over 50 languages including Chinese, Japanese, Korean, Spanish, French, German, and more
- **Multiple Translation Modes**:
  - **Translate**: Main translation interface with language set switching
  - **Translate Form**: Form-based translation with text area input
  - **Quick Translate**: Quickly translate to multiple target languages
  - **Instant Translate**: Instantly translate selected text (copy/paste/view)
- **Auto-Detect Language**: Automatically detects the source language
- **Natural Translations**: Leverages ChatGPT's AI for context-aware, natural translations

## Commands

| Command | Description |
|---------|-------------|
| Translate | Main translation interface |
| Translate Form | Form-based translation with text area |
| Quick Translate | Quickly translate to multiple languages |
| Instant Translate Copy | Translate selected text and copy to clipboard |
| Instant Translate Paste | Translate selected text and paste to active app |
| Instant Translate View | Translate selected text and show in HUD |

## Preferences

| Preference | Description |
|------------|-------------|
| Primary Language | Default source language (Auto-Detect recommended) |
| Secondary Language | Default target language |
| Auto Input | Automatically input selected text when opening |
| Default Action | Default action on Enter (Copy or Paste) |

## Supported Languages

## How It Works

This extension uses ChatGPT's free translation API (the same one used by [chatgpt.com/translate](https://chatgpt.com/translate)). No login or API key is required.

The translation is powered by OpenAI's GPT models, providing:
- Context-aware translations
- Natural language output
- Preservation of tone and meaning
- Support for idioms and expressions

## Privacy

- No API key required
- No login required
- Translation requests are sent directly to ChatGPT's servers
- History and training are disabled for all requests
