# OpenAI Translate Changelog

## [1.0.0] - 2026-01-30

### Added
- Initial release of OpenAI Translate extension
- Main translation interface with language set support
- Form-based translation with text area input
- Quick translate to multiple target languages
- Instant translate commands (copy, paste, view)
- Support for 50+ languages
- Multiple translation styles (natural, formal, casual, literal)
- Custom API endpoint support for compatible APIs
- Model selection (GPT-4o-mini, GPT-4o, GPT-4 Turbo, GPT-3.5 Turbo)
- Auto-detect source language
- Language set management
- Keyboard shortcuts for common actions
